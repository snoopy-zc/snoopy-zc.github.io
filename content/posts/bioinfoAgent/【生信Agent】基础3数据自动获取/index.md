## 1 公共数据检索

公共数据库
- GEO (Gene Expression Omnibus) 
    - <https://www.ncbi.nlm.nih.gov/geo/>
- TCGA (The Cancer Genome Atlas)
    - <https://www.cancer.gov/ccg/research/genome-sequencing/tcga>


```
#提示词

你是一个熟悉公共生信数据库和GEO数据挖掘的生物信息学助手。
我的研究方向是：【慢阻肺】。
请你帮我检索适合用于bulk转录组差异分析的公开数据集，优先从GEO数据库中筛选。
检索要求如下：
1. 数据类型优先选择bulk RNA-seq或表达谱芯片数据。
2. 物种优先选择人，如果没有合适数据，可以补充小鼠数据。
3. 必须包含清楚的分组信息，比如慢阻肺组织和正常组织，或者不同处理组之间的比较。
4. 样本量不能太少，每组尽量不少于3个样本。
5. 优先选择已经提供表达矩阵或supplement processed data的数据集。
6. 请不要只给我数据库编号，请整理成表格，包括GSE编号、研究对象、物种、数据类型、样本数量、分组方式、是否有表达矩阵、是否适合差异分析、推荐程度及下载链接。
7. 严格禁止编造数据集：如果某个数据集ID不存在，请明确说明不要编造。
8. 最后请推荐1个最适合新手练习的数据集，并说明理由。
请以列表形式输出为Excel表格，如不确定的信息，请随时和我沟通。
```



## 2 数据下载

**创建目录**

```
#提示词

请你在当前目录下创建一个标准bulk RNA-seq公共数据分析项目文件夹。
项目名称为：【GEO_bulk_analysis_project】。
请创建以下子文件夹：
1. raw_data：保存从数据库下载的原始数据。
2. clean_data：保存清洗后的表达矩阵和样本分组信息。
3. scripts：保存后续所有R脚本。
4. results：保存差异分析、富集分析和可视化结果。
5. report：保存分析记录和最终报告。
请同时创建一个README.md文件，用中文说明每个文件夹的用途。
```
**下载**

```
#提示词

你是一个熟悉GEO数据下载和R语言处理的生信助手。
我已经确定要分析的数据集是：【填写GSE编号】。
请你在当前项目文件夹中完成以下任务：
1. 检查当前项目文件夹结构是否包含raw_data、clean_data、scripts、results和report。
2. 使用合适的方法下载该GEO数据集的表达矩阵和样本信息。
3. 如果可以使用GEOquery，请优先使用GEOquery下载。
4. 如果GEOquery无法下载完整表达矩阵，请在GEO数据库官网检查supplementary files中是否有processed expression matrix并进行下载。
5. 所有原始下载文件保存到raw_data文件夹。
6. 请生成一个download_log.txt文件，记录数据集编号、下载时间、下载方式、下载到的文件名称和文件路径，保存到raw_data文件夹。
7. 下载完成后，请不要直接做差异分析，先告诉我当前下载到的数据包括哪些文件。
如果使用R语言进行下载，请输出一份R代码以便于我复现。
```

## 3 数据整理和清洗

**表达矩阵清洗**

```
#提示词

请你作为一个熟悉GEO转录组数据处理和清洗的助手，帮我使用R语言处理从GEO下载的转录组数据集。
先读取raw_data文件夹中的所有文件，判断每个文件的用途。
请帮我完成以下处理步骤：
1. 识别哪个文件是表达矩阵，哪个文件是样本信息，哪个文件是平台注释文件。
2. 探针ID到基因名转换：
判断表达矩阵中的基因ID类型，是Gene Symbol、Ensembl ID还是芯片探针ID；如果是探针ID，请根据平台注释文件转换为Gene Symbol；如果是Ensembl ID，请去掉版本号并转换为Gene Symbol；如果一个基因对应多个探针，取平均值
3. 数据清洗：
移除缺失值过多或无法注释的探针；移除低表达基因
4. 输出格式：
基因作为行名，样本作为列名；最终生成：数据集编号_clean_expression_matrix.csv，保存到clean_data文件夹。
5. 质量检查：
报告原始数据维度（探针数×样本数）；报告处理后数据维度（基因数×样本数）；报告成功注释率和清洗掉的数据比例
请输出清洗后的数据和一份处理报告，说明每一步的处理结果和最终数据。同时生成对应的R代码以便于我进行复现。
```

**分组信息表**
```
#提示词

请你继续整理当前GEO数据集的样本分组信息。
请根据GEO中的样本描述文件、metadata或series matrix文件，全程使用R语言完成以下任务：
1. 提取所有样本编号。
2. 判断每个样本对应的实验分组。
3. 如果分组字段不明确，请根据title、source_name、characteristics_ch1等字段综合判断。
4. 生成一个标准样本信息表：数据集编号_sample_info.csv。
5. 样本信息表至少包含两列：sample和group。
6. 如果能提取更多信息，可以增加tissue、disease_status、treatment、platform等列。
7. 请检查样本信息表中的sample名称是否与clean_expression_matrix.csv中的列名完全一致。
8. 如果不一致，请自动修正并记录修正规则。
9. 最后输出每组样本数量统计并说明你的分组依据。
请输出处理报告，同时生成对应的R代码以便于我进行复现。
```


## 4 验证数据

检查：
1. 分组区分是否合理。
2. 样本数量是否一致。
3. 表达矩阵是否一致。
4. 分组信息表是否一致。
5. 是否存在缺失值、重复样本或重复基因。
6. 表达矩阵是否为纯数值矩阵。
7. 每个分组的样本数量是多少。
