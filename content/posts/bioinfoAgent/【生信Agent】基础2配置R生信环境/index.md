## 1 安装R语言和RStudio

**预检查，提示词：**
```
1. 请你先检查我的电脑是否已经安装R、RStudio以及常用R包。
2. 请不要直接安装，先输出检查结果，并告诉我下一步应该做什么。
```

**安装，提示词：**
```
1. 任务：请帮我在当前电脑上安装 R 语言和 RStudio。
2. 系统检查：请先判断我的电脑系统类型和系统版本，确认适合安装的 R 与 RStudio 版本，尽量安装最新版本的前一个旧版本。
3. 安装要求：请自动完成 R 语言和 RStudio 的下载、安装和基础配置。
4. 路径要求：请避免中文路径和带空格的特殊路径，优先使用默认安装路径。
5. 验证要求：安装完成后，请自动打开终端或 R 控制台，验证 R 是否可以正常运行。
6. 输出要求：请记录完整安装过程，包括系统信息、安装版本、安装路径、是否安装成功，以及遇到的问题和解决方法。
```

**验证安装，提示词：**
```
为了验证R是否安装成功，请你按照我的要求进行操作：
1. 在本地安装好的R中运行，输出R语言的版本号及当前工作目录
2. 仅使用 R 自带的 **base** 绘图函数（**barplot**），不依赖任何需要额外安装的包，自动生成一组随机数，画一个带标题、X 轴标签、Y 轴标签的条形图，并生成一个**PNG**图片文件。
3. 将绘制图片产生的代码全部保存并生成R代码文件（包括随机数的种子），代码每一行或每一块都加中文注释，确保我可以看懂你在干什么。
4. 输出格式：直接给出一个完整的代码块，我能整段复制到 RStudio 运行。
```
